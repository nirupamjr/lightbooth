# LightBooth

LightBooth is a browser-based photo booth by nirupam.jr.

## Use it

Open `index.html` through HTTPS, such as GitHub Pages. Camera access is not available from a local `file://` URL on many browsers. Choose **just me** or **together**, allow camera access once, capture four photos, then review the full set and retake individual photos before decorating.

You can also upload four photos instead of using the camera. The decoration screen supports canvas sizes, borders, B&W/color presets, paper textures, finishes, and local PNG export.

Everything runs privately in the browser; no backend or account is required.
